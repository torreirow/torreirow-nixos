# Nginx Static Assets

Deze directory bevat statische bestanden voor nginx.

## 404 Error Page Image

**Verwachte locatie:** `404.png`

**Bron:** Kopieer van `~/Pictures/torreiro-website-404.png` naar `modules/static/404.png`

**Commando:**
```bash
cp ~/Pictures/torreiro-website-404.png modules/static/404.png
```

Deze image wordt gebruikt op de generieke 404 error pagina voor alle nginx sites.
